Обработка данных на сайте

Оператор данных посетителей страницы anastasiamedvedeva.ru/trevoga/ — Анастасия Евгеньевна Медведева. По вопросам обработки данных можно написать в Telegram.

Запись на знакомство

Вы можете написать Анастасии в Telegram, WhatsApp или MAX либо оставить заявку на сайте. Переход в мессенджер открывает переписку; сообщение отправляется только после вашего действия в самом мессенджере.

Форма запрашивает имя, фамилию, номер телефона, удобный способ связи, а при выборе Telegram — имя пользователя. Тему обращения можно указать по желанию, кратко и без личных или медицинских подробностей. Пожалуйста, не указывайте в форме диагнозы, сведения о состоянии здоровья и интимной жизни.

Данные заявки используются только для ответа и согласования знакомства. Форма передаёт их через Yandex Cloud Functions в личный Telegram-чат Анастасии с помощью бота. Содержание заявок не публикуется на сайте и не записывается в журнал функции. Переписка и уведомления в Telegram сохраняются до удаления Анастасией. Если вы хотите уточнить или удалить свои данные либо отозвать согласие, напишите ей по этому контакту.

Работа сайта

Страница размещена на GitHub Pages. Для её загрузки браузер передаёт хостингу технические сведения о запросе, включая IP-адрес. Подробнее — в уведомлении GitHub о конфиденциальности.

Статистика

На странице предусмотрено подключение Яндекс Метрики. Когда счётчик будет активирован, он загрузится только после вашего нажатия «Разрешить». Метрика может обрабатывать сведения о посещении, источнике перехода, устройстве, браузере, IP-адресе и файлах cookie. Мы также будем учитывать достижение ключевых разделов страницы и нажатия на кнопки записи. Текст вашего сообщения в Telegram и содержание консультации в Метрику не передаются. Вебвизор, карта кликов и автоматический учёт переходов по ссылкам выключены.

Данные статистики передаются ООО «ЯНДЕКС» согласно условиям Метрики и политике Яндекса. Если вы выберете «Не разрешать», счётчик не загрузится. Изменить выбор можно через «Настройки статистики» внизу страницы. Отзыв разрешения прекращает будущую загрузку счётчика, но не удаляет уже переданные сведения; по вопросам доступа, уточнения и удаления данных напишите по контакту выше.
