# Заявки с лендинга «Тревога»

Страница `/trevoga/` размещается на GitHub Pages. Она отправляет JSON через `POST` на отдельную функцию Yandex Cloud. Функция проверяет заявку и отправляет письмо на `fly.medvedeva@yandex.ru` через SMTP Яндекс Почты. Отдельный пароль приложения хранится только в переменной окружения функции.

## Подключение

1. В настройках Яндекс ID для `fly.medvedeva@yandex.ru` создать отдельный пароль приложения для Почты. Не публиковать пароль в GitHub, файлах сайта или переписке.
2. В Yandex Cloud создать Cloud Function на Python с кодом `yandex_function/index.py`, точка входа `index.handler`. Установить переменную окружения `YANDEX_MAIL_APP_PASSWORD` с этим паролем. Включить публичный HTTP-вызов, чтобы браузер мог отправлять заявки.
3. После проверки политики обработки персональных данных и реквизитов оператора вставить URL функции в атрибут `data-endpoint` формы в `/trevoga/index.html`. Пока атрибут пустой, форма не показывает ложное подтверждение отправки и предлагает написать в мессенджер.
4. Отправить одну тестовую заявку с опубликованного домена `https://anastasiamedvedeva.ru/trevoga/`, убедиться, что письмо пришло на почту и сайт показал успешную отправку. Проверить также ошибку отправки.

Функция принимает запросы с `https://anastasiamedvedeva.ru`, проверяет имя, фамилию, телефон, способ связи, согласие и Telegram-ник, если выбран Telegram. Она ограничивает размер сообщения, игнорирует поле-ловушку для простых ботов и не пишет содержимое заявок в лог. Это не полная защита от спама; при большом потоке заявок стоит добавить ограничение частоты запросов на уровне инфраструктуры.

Поскольку свободное поле может содержать сведения о здоровье, перед включением формы нужно завершить политику обработки персональных данных. На странице есть просьба не указывать медицинские подробности; это не техническая гарантия, поэтому при необходимости свободное поле следует убрать.

Проверка кода: `python3 -m unittest discover -s trevoga/backend/yandex_function -p 'test_*.py'` из корня сайта.
